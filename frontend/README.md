# Orbita frontend

PWDRZ-160 experimental React 19 + Vite 7 + React Router 7 SPA, served on port `3001` in local development. It communicates with the gateway, not directly with Spring Boot.

Production files are served by Express on port 3000. In development Vite forwards `/api` and `/ws` to Express. See the [spike runbook](../docs/spikes/pwdrz-160-vite-spa/README.md) for comparison commands.

The source layout retains PWDRZ-149 ownership boundaries. See the [frontend target architecture](../docs/guides/frontend/README.md) for the baseline FSD ownership plan; `src/app/routes.tsx` explicitly owns the SPA route tree. Directory names such as `(auth)` and `[slug]` no longer have framework magic.

## Quick start

```bash
# Run this block from the repository root.
npm ci
cp .env.example .env

# If frontend/.env does not already exist, create it from the template.
cd frontend
cp .env.example .env

npm run dev -- --port 3001
```

Open `http://localhost:3001`. Start the gateway and backend as described in the repository [README](../README.md).

Dependency installation belongs to the root workspace and shared lockfile.
Root Nx commands and direct-service escape paths are in the
[monorepo guide](../docs/guides/monorepo.md).

## Authentication and API boundary

- Access tokens stay in memory; refresh tokens are `HttpOnly` cookies. Do not add browser storage for tokens.
- Implemented API DTOs, operations and TanStack Query bindings are generated by pinned Orval from `backend/openapi.json` into `src/shared/api/generated/` and committed. They use `src/shared/api/client/api.ts` and relative `/api` through one custom mutator. No public API URL is compiled into the bundle.
- The forum feed loads paginated data through `src/shared/api/forum/useForumPosts.ts`. The home page shows the first page of the same feed (`src/app/(main)/_ui/HomeFeed.tsx`).

Run root `npm run api:generate` after an intentional contract change and
`npm run api:check` to verify the complete output without changing it. Never edit
generated files. See the [API bindings workflow](../docs/guides/api-bindings.md)
for backend export, cache keys, transport, CI and remaining provisional contracts.
